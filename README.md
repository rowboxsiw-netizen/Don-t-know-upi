
# Bharat Singh - Premium Developer Portfolio 2026

A futuristic, high-performance developer portfolio built with React 18+, TypeScript, Tailwind CSS, and Framer Motion. Designed for 2026 industry standards.

## ✨ Features
- **Modern Design**: Glassmorphism, blurred backdrops, and interactive floating elements.
- **Performance**: Optimized for fast loading and accessibility.
- **Theming**: Seamless dark and light mode toggle.
- **Responsive**: Mobile-first architecture.
- **Interactive**: Scroll-triggered animations and 3D hover effects.

## 🚀 How to Run Locally

1. **Clone the project**
   ```bash
   git clone <repository-url>
   cd bharat-singh-portfolio
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm run dev
   ```

## 🌍 Deployment Guide

### Vercel Deployment (Recommended)
1. Push your code to a GitHub repository.
2. Go to [Vercel](https://vercel.com) and sign in.
3. Click "New Project" and import your repository.
4. Set the framework preset to **Vite** (if using Vite) or **Next.js**.
5. Click **Deploy**. Vercel will automatically handle SSL and global CDN.

### Netlify Deployment
1. Log in to [Netlify](https://netlify.com).
2. Click "Add new site" -> "Import from existing project".
3. Choose your Git provider and repository.
4. Build command: `npm run build`
5. Publish directory: `dist`
6. Click **Deploy Site**.
